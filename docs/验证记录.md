当前机器无法执行 Windows EXE，**Windows 原生安装、DPAPI、下载签名验证与 GUI 操作仍待 Windows 验证**。仓库附 Windows CI，会运行 Python 3.14 测试、DPAPI 往返、原生环境检查，以及健康环境不弹准备界面并自动打开首页的检查；是否通过以 GitHub Actions 的实际结果为准。

真实 Gemini 识别需要有效 API Key 与原始商品图片，本次使用模拟 API 响应验证集成；不代表真实识别准确率。用户截图显示黑色原图已被识别为黑色，无法仅凭截图确定是置信度阈值还是复核标记阻止配对；本次针对该路径补充了复核及原因展示，没有降低配对阈值。首页与配对预览来自实际 Qt 界面，配对预览中的商品图片与结果为演示数据。
