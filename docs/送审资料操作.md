# 送审资料生成器


## 准备输入表与主数据

保存程序的 **输入模板**，填好 `款号、款式、尺码、颜色、面料、成本`。也可以用“商品名称”作款式列。上下装不用手填，会按款式判断；旧表带有上下装列也可以继续用。

另选主数据表。主数据至少包含 **新品类层级编码及标费档次** 工作表：品类来自 B/C/D 列，中类、标准价和标费来自 H/J/L 列。“尺码表”“颜色”工作表有的话也会照常使用，没有的编码会留空。

## 填写面料信息

像这样写清原文：`面料:100%锦纶 里料:100%棉 填充物:90%鸭绒10%羽毛`。成分、标点和比例会保留并分别放进对应列；不把“棉面料”猜成棉填充。


## AI 辅助与结果核对

在首页配好 API 和模型，再启用组件内的 AI。上下装可仅凭款式名称判断；缺失的品类、标准等有图片时再辅助识别。没有证据的执行标准不编造，查不到的项目仍留空并提示。

款式写 **加绒针织裤** 或 **针织裤（加绒）** 时，按“针织裤”匹配，匹配到的标准价加 20；原商品名称保留，成本价、吊牌价不因此改变。没有基准价不单独填 20，“不加绒”不加价。

生成后看看黄色格与 **AI核对** 页，再决定送审。关闭 AI 或请求失败时，明确的款式词可回退本地规则；套装、连体等拿不准的上下装请留意核对提醒。
