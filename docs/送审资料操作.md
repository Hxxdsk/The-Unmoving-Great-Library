# 送审资料操作

1. 保存程序提供的 **输入模板**，填写前七列；可用“商品名称”替代“款式”。
2. 图片非必填。在“图片”列插入浮动图、WPS/Excel 单元格图，或填本地图片文件路径；图片应对应本行款号，同款后续行可复用该款图片。不下载远程图片链接。
3. 选择主数据及输出位置。主数据至少包含“新品类层级编码及标费档次”；品类读 B/C/D 列，价格与标费读 H/J/L 列，支持合并单元格。另有“尺码表”“颜色”时照常匹配，没有时相应编码留空。
4. 使用 AI：填入 Key → 检测模型 → 选择模型 → 勾选 **AI 面料 / 图片补全** → 开始生成。已保存 Key 可以复用，模型独立记忆。未配置或关闭 AI 时使用本地分列与规则。
5. 面料输入如 `面料:100%锦纶 里料:100%棉 填充物:90%鸭绒10%羽毛`，会移入三个对应列。标签、空格、标点和比例保留，面料名称取第一个实际成分名称。AI 改写或遗漏原文的结果会被拒绝并回退。
6. 品类、小类、安全类别或执行标准缺失且有图片时，AI 根据图片和输入面料识别类型，从主数据候选选择；不生成不存在的公司编码。没有图片时不触发图片补全，未匹配项目留空。
7. 图片补全成功后检索适用的现行标准，需引用官方标准平台并确认实施日期。查不到、模型不支持联网、适用条件不明或尚未实施时，不填入推测值；已有规则值保留，未匹配值留空。
8. 输出后检查黄色字段与 **AI核对** 表，查看原面料、分列结果、图片判断依据、标准旧值/新值、官方来源及提醒。发现缺失颜色且主数据已有颜色库时，按原流程手动连接并重新生成。

同一面料、同款图片会复用识别结果；同一次生成中的未确认结果也不逐行重复请求。可取消后台任务，取消后不公布半成品；输出不能覆盖输入或主数据。

“裤”的本地规则只命中针织裤或梭织裤。其他原固定项、成本及吊牌价规则保留。当前单一品类主数据也可生成；程序不会猜测缺少的尺码和颜色编码。
