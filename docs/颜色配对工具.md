# 商品图片颜色配对


## 准备资料

选一个同时放着商品资料表和款号文件夹的目录。表格要有 **供应商款式编码、颜色、商品编码**；每个款号的图片放在同名文件夹。

想用 AI 时，每款放一张名为 `颜色.jpg` 或 `颜色.png` 的总览图。只做手动配对可以不放，也不用 API。

```text
资料目录/
├─ 商品资料.xlsx
└─ 款号A/
   ├─ 颜色.png
   ├─ 1.jpg
   └─ 2.jpg
```

## 识别与配对

读取表格，再识别颜色。同名色先配好，名称不一致或有遮挡时会标记待核对。单独重试不确定的图片，最多三轮；可靠的图不反复上传。


## 核对与导出

确认每个颜色指向正确原图，再输出。同色各尺码共用原图；只需要一部分颜色时勾 **仅输出已配对**。

成品放在 `_商品编码图片/新批次/款号/`，保留原图和旧批次，并附配对记录。相同内容可复用识别结果，想重新辨认时点 **重识别当前款号**。
