# 帕秋莉的颜色书签

“衣服叠在一起的时候，先别急着认色。我们找两处没有被挡住的布料，再看看总览旁边写的字。”

## 第一张纸条：找到这一摞

选一个同时放着商品资料表和款号文件夹的目录。表格要有 **供应商款式编码、颜色、商品编码**；每个款号的图片放在同名文件夹。

想用 AI 时，每款放一张名为 `颜色.jpg` 或 `颜色.png` 的总览图。只做手动配对可以不放，也不用 API。

```text
资料目录/
├─ 商品资料.xlsx
└─ 款号A/
   ├─ 颜色.png
   ├─ 1.jpg
   └─ 2.jpg
```

## 第二张纸条：看看她认得对不对

读取表格，再识别颜色。同名色先配好，名称不一致或有遮挡时会留下待核对书签。不确定图片单独复读，最多三轮；可靠的图不反复上传。

“使用的原图”下拉列表可以悬停看右侧预览，光看不会改选择。双击行能等比看全图，窗口变大图片也会跟着变大。滚轮只滚动，不改选。

## 最后一张纸条：核对，再装订

确认每个颜色指向正确原图，再输出。同色各尺码共用原图；只需要一部分颜色时勾 **仅输出已配对**。

成品放在 `_商品编码图片/新批次/款号/`，原图和旧批次都留好，并附配对记录。相同内容可复用识别结果，想重新辨认时点 **重识别当前款号**。

浮动的小帕秋莉可以点击、拖动、靠边趴下；可以自由拖动她，或点击收起提示。收起她只是让本次安静一点，处理任务照常继续。
