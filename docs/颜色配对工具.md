# 颜色配对操作

1. 选择含 Excel 与款号文件夹的目录，选择表格并读取。
2. 表格必须有 `供应商款式编码、颜色、商品编码`；支持 `.xlsx/.xlsm`。供应商款号对应下一层同名文件夹。
3. AI 模式需在文件夹放一张 `颜色.jpg/.png` 等颜色总览图，再填入 Gemini Key、检测并选择模型。手动模式不需要 Key 或颜色图。
4. 点击 **AI 识别全部款号**，或逐行点击列表选图。每色一张，不重复使用；同色所有尺码共用这张图。
5. 先核对 **名称不一致 · 请核对** 和 **AI建议 · 请核对** 的行。双击行放大原图；改选时，已被另一颜色占用的图片需先解除原配对。
6. 点击 **确认配对并输出图片**。勾选 **仅输出已配对** 可输出部分颜色，确认框会显示跳过数量。

```text
资料目录/
├─ 商品资料.xlsx
├─ 款号A/
│  ├─ 颜色.png     # AI 需要；纯手动可省略
│  ├─ 1.jpg
│  └─ 2.jpg
└─ 款号B/
   └─ ...
```

常见款号不超过 12 张原图时，只发一次批量识别请求。同名匹配先锁定，剩余名称按图中主体颜色和名称含义寻找一对一建议；不确定的建议会标记待核对。相同内容/模型复用缓存，图片、表格颜色或模型改变后不复用旧结果；**重识别当前款号** 强制重新请求。可信度为模型自评，需核对。

顶部可收起设置；左侧可搜索款号；原图缩略图和完整日志默认折叠，底部始终显示最新日志。图片下拉框滚轮不改选；完整日志可取消 **跟随最新** 查看旧记录。

输出写入 `_商品编码图片/新批次/款号/商品编码.原扩展名`，不覆盖原图或旧批次，包含 CSV/JSON 配对记录、异名备注和 SHA256。图片与表格的非法编码、重复商品编码冲突、链接到目录外等问题会在读取或输出时提示；不会按文件序号猜颜色。

Windows 会加密记忆 Key，普通偏好不保存明文。AI 仅接收颜色图、商品图、文件名和颜色名称，不发送整表或商品编码。其他系统没有凭据保护时仅本次使用。各工具独立记忆模型，首次配置后可复用已保存的 Key。
