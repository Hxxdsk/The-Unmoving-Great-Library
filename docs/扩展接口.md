# 新增独立工具

`suite/registry.py` 定义工具信息，`suite/extensions.py` 是扩展注册入口。新工具在独立子进程运行，不共享其他工具的窗口、变量或任务。

1. 在 `plugins/` 创建模块，实现无参数 `main()`，在此建立自己的 GUI 与事件循环。可参考可直接运行的 `plugins/example.py`。
2. 在 `suite/extensions.py` 的 `register_extensions()` 中注册：

```python
from .registry import Tool, Dependency

register(Tool(
    key="extra",
    title="新功能",
    subtitle="简短用途",
    description="说明输入与输出",
    entrypoint="plugins.example:main",
    # 仅当新工具需要额外第三方运行库时声明；模块名与 pip 包名可不同。
    # dependencies=(Dependency("requests", "requests"),),
))
```

`key` 使用小写字母、数字与下划线，以字母开头，不得与现有入口重复。`entrypoint` 使用 `模块:函数`。注册函数只登记信息，不在首页进程创建扩展 GUI 或执行业务任务。

3. 首页自动显示新卡片；超过 4 张卡片时启用滚动区。`python suite_entry.py --tool extra` 可以单独启动，日志自动写入 `extra.log`。
4. `runtime_probe.py` 会检查扩展模块与声明的依赖。原生启动器只补齐失败的库，复用健康环境；改变源码后不复用旧检查结果。源码开发时也可把新依赖补入 `requirements.txt`。
5. 运行 `python tools/package_release.py` 重新打包。`plugins/` 自动进入 ZIP，Python 扩展不需要重建 Go EXE；修改原生启动行为或图标资源才需要重建 EXE。

统一外观可使用 `color_tool.ui.STYLESHEET`、`suite.widgets.ClickOnlyComboBox`（防滚轮误选）、`FollowLog`（日志跟随）、`suite.branding.mascot()`；Tk 工具可用 `suite.legacy.common_ttk_theme()` 与 `suite.palette`。装饰图片位于 `assets/patchouli.png`，窗口图标为 `assets/toolbox.ico`。

新的 Tk 功能可使用 `suite.ai_controls.GeminiPanel(..., component="extra")`：复用加密 Key，按组件保存模型；`suite.tasks.TkTask` 负责后台队列和主线程界面更新。AI 非敏感结果可用 `suite.cache.ResultCache` 缓存。各工具适配层位于 `suite/*_adapter.py`。

组件图标按 `assets/logo-<key>.png/.ico` 放置，首页会使用对应图标；没有对应文件时使用默认装饰。五个现有入口已有独立图标，原始高清图保存在 `assets/logo-<key>-original.png`。
