# 抖店批量上架


## 连接 Edge

第一次在 **首次安装扩展** 查看目录，到 `edge://extensions` 开启开发人员模式并加载解压缩的连接扩展。完成一次 **连接 Edge** 后会记住配对；当前扩展版本为 **1.3.0**。

以后重启电脑、浏览器或工具箱都会自动恢复连接。浏览器没开或扩展停用时只是等待，不用反复连接；只有确认扩展被删除才提示重新安装。恢复连接不新开页面、不抢焦点。关机期间任务不能继续运行，配对记录仍保留。

## 准备素材目录

选择资料根目录，每款使用同名文件夹，里面准备 `800、3.4、白底、详情、水洗标、颜色` 六个目录。800 和 3:4 使用按名称升序排列的前5张。

颜色目录中每色放一张单色图，可再放带颜色名的多色总览图；尺码图也放这里，**文件名不限，不需要改名**，不需要单独尺码文件夹。开始任务后 AI 按实际内容找出尺码表和多色对照图；读取目录时显示“AI识别”，不再因为没有名为“尺码”的文件而阻止执行。

真正的尺码图应有尺码与测量值、身高体重推荐等逐项对应的表格。只有“大码可穿90-300斤”等广告文案的单色商品图不会据此当作尺码图排除。未能确认尺码表时会明确提示，避免猜测尺码。

多色图和尺码图参与初始详情，不当作后续单色规格图。配色优先读取对照图每格下方的真实颜色名，再与单色图的服装主体比较；使用单色原图细节，排除宣传区域、商标、皮肤和背景的影响，不能可靠区分时跳过。

## 填写标题并开始任务

每款旁填写标题，勾选要处理的货号，确认价格和库存。已有任务记录的款会跳过，需要重做时先 **重置选中任务记录**。

开始前可在 **同时进行任务数** 输入数字，默认 1（逐款处理）。例如填 3，就最多同时处理 3 款，某款完成后立即开始下一款。勾选 **全部并行**，本次勾选且可执行的所有货号同时开始；资料缺失或已有记录的款仍跳过。并行设置会记住。

工具在同一个独立后台工作窗口为每个任务新开标签页，按实际页面从上往下填写。任务完成后保留在保存草稿后的页面，不关闭、不复用该页；后续批次也新开标签页。已有完成页不计入“同时进行任务数”，这个数字限制的是正在执行的任务。其他窗口可以照常使用，别手动改正在运行的工作页。

“单商品”菜单重绘或收起时会自动重新展开，并在出现后直接选择。生成按钮暂时变化会在等待时间内重新检查；已确认点击后等待页面切换，不重复生成，也不强制点击禁用或被遮挡的按钮。

所有素材在 Windows 上调用系统名称排序规则，按资源管理器的“名称升序”顺序读取（不跟随日期、大小或降序视图）。详情图逐张等待上传完成后才传下一张，避免网站按网络完成先后排错；例如 `!0.jpg、1.jpg、2.jpg、10.jpg` 会按这个顺序上传。不会重命名或改写原图。

初始详情使用颜色目录，进入编辑页后换成完整详情；颜色按网页已有项匹配，缺失或不可靠的先跳过。尺码体重只填网页有的对应项，格式为 `xx-xx斤`。价格库存填入批量栏并点击批量设置。

## 确认草稿保存结果

保存前会选择网站第一条推荐标题，按输入框实际内容确认，弹层未消失不再误报。工具只保存草稿，不发布商品；确认网页保存回执后才记为完成，并腾出并行名额开始下一款。

保存时断线或结果不明确会留下 **待核对**，不要直接重复保存。先到抖店核实结果，再决定重置记录。素材不完整等问题会记录并继续其他款，没拿到回执不会假记为成功。

## 流程记忆与重试

可以为不同店铺新建流程配置。阶段验证成功后才记住方案，下次优先复用；失败方案暂停重放，失败原因供 AI 参考。旧版未经阶段验证的记忆先重新验证，不需要你手动指导。

定位不到时自动观察当前页面并有限重试，不再等待用户指导。图片上传中遇到驱动断线，会有限尝试重连原编辑页；无法确认原页则保留现场，避免重复创建商品。

停止时不再启动排队货号，正在运行的任务在检查到停止后结束，已经打开的页面和已确认保存的草稿保留。

## 识别速度与缓存

常规带对照图流程合并为两次模型请求：一次分类素材，一次匹配颜色并读取尺码体重。不再固定追加两轮对照图复核；缺少必要匹配信息时仍会针对性复核，体重列未读清时会放大复读。

可靠的分类和配色结果保存在资料根目录的 `_抖店识别缓存`，重做相同素材时可复用。缓存按图片内容、文件名、模型及网页颜色候选校验，改图、换模型或颜色候选变化会重新识别；不缓存图片内容和 API 密钥。只缓存通过校验的完整配色/体重结果，不把不确定配色固定下来。必要时可删除该缓存目录强制重新识别。
