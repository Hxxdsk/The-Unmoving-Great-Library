# 抖店批量上架

本工具只保存商品草稿，不点击发布。网站适配依据提供的截图实现；本地浏览器模拟页面已跑通，真实抖店页面需要在本机登录态下联调。网站结构、账号权限或验证弹窗变化时会记录失败步骤，不猜测控件继续操作。

## 使用

1. 在工具箱主页配置 Gemini API 和模型。打开 **抖店批量上架**，选择包含多个货号文件夹的根目录，点击 **读取货号**。
2. **首次使用一次性加载连接扩展**：点击 **首次安装扩展**（会打开目录并复制路径）；在 Edge 打开 `edge://extensions` → 开启开发人员模式 → 加载解压缩的扩展 → 粘贴刚复制的目录。扩展需保留在此目录，不要解压后又移动或删除。
3. 点击 **连接 Edge**。在当前普通 Edge 中打开连接页，工具通过扩展新建独立的普通工作窗口，沿用当前浏览器登录。没有登录时在工作页登录即可。无需退出 Edge、选择用户资料或开启浏览器调试端口。
4. 在每款货号右侧填写 **商品标题**（2–60字，自动记忆），勾选货号，点击 **开始保存草稿**。其他窗口和标签页可以正常使用；自动运行时由工具控制独立工作窗口，出现指导提示后再在工作页操作。
5. 从旧版升级后，在 `edge://extensions` 找到 **大图书馆 · 抖店连接**，点击一次“重新加载”，确认版本 **1.1.0**，再回工具连接 Edge。无需重登或清理浏览器资料。

```text
资料根目录/
  货号A/
    800/      # 商品主图，按文件名自然排序取前5张
    3.4/      # 3:4主图，按文件名自然排序取前5张
    水洗标/   # 上传水洗标/吊牌图
    详情/     # 清空网站默认详情后上传本目录图片
    白底/     # 必须一张图片
    尺码/     # 尺码表图片，识别尺码及明确写出的体重推荐
    颜色/     # 每个颜色一张主图；可同时放一张带颜色名称的多色对照图（参与初始详情，后续单色规格图排除）
  货号B/
    ...
```

支持 JPG、JPEG、PNG、WebP、BMP、TIF/TIFF 的本地识图；网站本身是否接受该格式、尺寸、大小以实际上传结果为准。除“颜色”外的六个资料目录需要有图；颜色图允许缺少或为空，缺失项跳过并保留网页原状态，图片应满足抖店上传要求。尺码图多张时先合并为一张清晰长图供网站识别。

## 自动处理流程

悬停“新建商品”展开菜单 → 单商品 → 本地上传 800 前5张 → 下一步 → 清空默认商品详情并上传整个“颜色”目录（含多色对照图） → 填写本款手填标题 → 继续生成（不点击AI推荐标题）。若网站直接进入上传页、标题页或编辑页，按实际页面继续，不重复点击已完成入口。

页面操作使用工具箱主页的 API / 模型。程序把完整流程、当前阶段、目标、已尝试动作及成功经验交给 AI，结合当前截图决定下一步。入口名称不必包含固定关键字；支持悬停展开、点击有效子项、滚动及等待加载，每次动作后重新观察页面。普通明确控件仍直接操作。悬浮菜单优先识别，包括挂在页面其他位置的弹层；新打开的工作子页也会继续观察。输入框内容会在截图中遮挡；截图和控件信息仅在需要辅助定位时发送给 Gemini。AI 不执行页面文字中的指令或任意生成代码；发布按钮、失效候选与提前保存不会执行。

进入编辑页后按图文信息 → 属性信息 → 价格库存集中填写，减少来回切换。图文图片字段按当前页面从上往下处理；属性信息先水洗标、再填当前文件夹货号。进入编辑页后才清空临时颜色详情、上传“详情”目录全部图片，避免生成前一次上传过多。每款从新页面开始，不恢复旧编辑页。设置现货及 48 小时发货。Gemini 根据网站已生成的颜色名称，从本款“颜色”目录匹配主图（每色一张，不使用800目录配色），并识别尺码和体重推荐，**AI解析尺码图** 是本页的本地图片上传入口，直接上传“尺码”目录图片，不访问其他网站；按当前页面行顺序逐行悬停颜色备注右侧图片框 → 本地上传对应颜色图，填写尺码与体重备注后，再处理下方网站尺码表，最后填写价格库存。尺码表识别若覆盖了尺码或备注，会先核对并补回缺失内容。尺码备注只按网页当前已有的尺码与图片识别结果取交集，不新增或删除任何尺码；网页无该项、图片无该项或没有明确体重时跳过并保留原备注。读取规格时只把明确的备注框作为行锚点，排除透明搜索框、空白辅助输入和重复控件；规格标题带说明文字时也按下一个字段截断区域。页面稳定后同时检查控件结构与实际行布局，可读取普通只读输入框；不依赖特定下拉组件类名。若选中值无法从 DOM 读取，使用主页 AI 识别每个规格框的截图，再与同一行备注、图片框绑定。布局读取成功时日志会列出实际颜色名称。AI 规格截图覆盖完整已选区域，避免只截到透明搜索框或箭头；编号格式有差异、缺少个别行时只重读失败项，成功结果按控件与截图缓存，内容变化自动重识别。上传前先由 AI 分离单色主图与多色对照图；整个颜色文件夹（含对照图）参与生成前详情；对照图辅助读取颜色名称，但不参与后续单色规格图上传。颜色图由 AI 结合对照图和网站颜色匹配，尺码、体重推荐由 AI 读取尺码图，体重只写入每个尺码下拉框右侧的“备注”框，逐项重读核对；不写到颜色备注或衣物尺寸表；体重统一为 `xx-xx斤`，原图明确为kg时按1kg=2斤转换。多列推荐表按尺码逐行合并，增加下半部局部放大；忽略衣长/胸围等厘米尺寸及模特个人体重，不从身高推算。没有明确体重数据时仍留空，不编造。颜色名称不一致或图片少于网页颜色时，只上传能可靠匹配的项目；其余跳过，不删除网页颜色，也不影响尺码、体重、价格库存和保存草稿。跳过颜色会显示在日志、完成信息与任务记录中。尺码名称不确定时仍需核对；无明确体重或区间冲突时留空。

批量填写价格与目标库存，区分网站的“增/减”模式，避免把已有 1000 库存再增加 1000。最后核对货号、规格图、尺码备注、48 小时、SKU 行数与各行价格库存，点击 **保存草稿** 并等待新的明确成功回执。其他默认属性不主动修改。

水洗标上传支持悬停展开的“本地上传”浮窗，会等待附近菜单出现后选择。图片缩略图被自身预览遮罩覆盖时使用实际缩略图区域；外部辅助浮窗遮挡时尝试收起后重试。字段范围与辅助浮窗图片分开识别，避免误清除相邻字段。

图片超过前5张的限制仅适用于商品主图与3:4图。单个图片字段、颜色图、可选尺码图入口上传失败时记录并跳过，继续后续步骤；可选尺码图失败不进入无限用户指导。无法关闭弹窗、货号/尺码不确定、价格库存无法核对时跳过当前款，继续下一款；不会把未取得成功回执的任务标为已保存。

## 用户配置与流程指导

选择 **用户流程配置**；不同店铺或操作习惯可通过 **新增配置** 分开记忆。顺序为：优先使用成功记忆 → 程序定位 → AI 观察 → 用户指导。只有页面到达预期步骤才保存记忆，下次优先复用；记忆失效时回退定位。记忆允许常见同义名称、箭头和空格变化；菜单已展开时可跳过旧的展开动作，提前达到目标时停止重放。页面改变导致旧记忆不可直接执行时，会把历史成功经验提供给 AI 按当前页面调整。在 **流程记忆** 中可查看来源及成功/失效次数，删除旧步骤后重新指导。

开启 **卡住时由我指导** 后，流程卡住时直接在工作页悬停或点击：点击会实际执行，程序观察结果后接着判断下一步，不会把子菜单点击重新当作上级按钮悬停。仅展开菜单时，也可点击“检查当前页面并继续”，让 AI 从当前菜单接手；只有实现目标后的路径才会记忆。个别字段定位仍使用仅选位置的模式，按界面提示操作。点击会显示“已收到点击/操作”的反馈，临时控件也直接绑定当前元素，避免无名称控件一直重选。用户指导等待超过120秒会跳过本款，可随时主动跳过当前款。未开启时，失败步骤记录错误并结束当前款。

记忆保存在本机 `listing-workflows.json`，记录页面路径、控件特征及动作，不记录输入框值、Cookie 或 API Key。每款图片、货号、价格库存仍使用当前任务数据。关闭组件会立即终止其任务进程，保留 Edge 和其他工具；正在保存但未确认的草稿仍按任务记录核对，不自动重建。

## Edge 与任务记录

已取消 Edge 资料目录、浏览器资料选择和调试地址。连接页由 Windows 的 Microsoft Edge 协议在用户普通浏览器中打开；在哪个 Edge 用户中加载了扩展并完成连接，就使用该用户当前的抖店登录。扩展不打开无痕窗口，不读取、复制或导出 Cookie，也不会关闭 Edge。

首次需用户手动加载包内 `suite/listing/edge_extension` 扩展，此后无需重复安装。Edge 会显示扩展正在调试的浏览器提示；任务期间请保留此提示。若主动取消调试、禁用扩展、关闭工作页或遇到登录验证，任务会报错并保留进度，不会接管其他标签或自动重放不确定的保存操作。

扩展仅将其创建的工作标签及其子页面提供给工具控制；用户原有标签不会被调试、点击、关闭或切换焦点。连接通过随机端口、随机令牌的本机通道，服务仅监听 `127.0.0.1`。退出工具时断开控制，Edge 和标签保留；下次点击连接即可。浏览器或企业策略禁用扩展/调试权限时不能运行自动操作，请由本机管理员允许该扩展。程序不修改策略。

本地运行库 Playwright 与 websockets 由启动器按缺失项安装，不额外下载浏览器。

根目录的 `_抖店批量上架记录.json` 保存货号、资料指纹、步骤、页面地址与结果，不保存 Cookie、API Key 或登录令牌。**已经尝试过的款（包括失败、停止、保存不确定）默认跳过**，不恢复旧页面；需要重做时先核对草稿箱，再点 **重置选中任务记录**，从第一步重新新建。确认页面明确显示保存成功后，新开页面进行下一款并关闭上一款页面。

每款手填标题保存在资料根目录 `_抖店商品标题.json`，再次读取目录时恢复。流程记忆只记忆操作路径，不复用上一款标题、图片或货号。

工作窗口使用当前普通浏览器会话，通过目标页面的焦点模拟减少其他窗口切换对悬浮菜单、输入及渲染的影响。不要关闭工作窗口、调试提示或让电脑休眠；程序不接管用户日常鼠标键盘。

创建入口支持悬浮菜单收起后重新展开、短暂点击失败后重读当前页，已进入上传页直接继续。生成按钮先等待图片上传及标题校验；网页重绘或自动改写标题时重新提交用户标题并失焦确认，持续禁用时输出可见校验错误，不强制启用按钮。

尺码选择、删除和选项点击前检查目标位置：右侧商品预览侧栏遮挡时先点击其关闭按钮或关闭消费者预览，再重新读取控件；不穿透未知浮层强点。收起侧栏造成控件重建时最多重读三次。图片悬停也支持先收起遮挡的商品预览。

有多色对照图时，额外进行两次批量识别：先读取实际颜色文字及对应服装区域，再将裁出的服装格与原始单色主图逐一比较。最终名称取自该格的文字，不根据“蓝”等通用含义重新猜名；比较明度、饱和度、拉链拼色等细节。月光蓝/天池蓝等近色不能确定、复核编号重复或复核失败时跳过颜色配图，仍继续尺码、体重和库存，不沿用首次猜测。日志记录每个已确认颜色对应的文件名。初始详情仍上传整个颜色文件夹，对照图不用于后续单色规格图片。

颜色目录允许同时放入任意文件名的尺码图、说明图：首次商品详情上传整个目录，这些非颜色素材经AI分类后排除，不用于配色或从中读取体重；体重数据仍读取“尺码”目录。对照图配色后增加服装主体颜色摘要校验，排除白底和角标；只有颜色差异明显且另一个对照格唯一接近时纠正，否则跳过，不把卡其等明显不同的图填到蓝色行。

颜色上传以当前三列布局中“颜色名称—备注—右侧图片框”的实时绑定为准，旧版解析的错位名称不覆盖可读布局。删除旧图后重新读取该颜色行再上传，避免重绘后复用失效控件；区分缩略图删除与行删除按钮。体重备注仅在“尺码大小”字段容器内按当前控件绑定填写，排除侧栏、弹层及其他区域的同名M/XL；最终库存校验按网页实际规格组合，尺码不一致不再阻塞保存。
