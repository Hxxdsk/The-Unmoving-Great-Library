# 帕秋莉的双页相册

“正面往前站一点，背面跟上来……嗯，先确认是同款同色，再装订。”

加载图片或多个文件夹，顺序会先保留。想请 AI 辨认时再点 **智能排序**，加载本身不自动调用 AI。

看看每一对是否同款同色、正面在前、背面在后。徽标可以点击修正，图片可以拖动调整；**识别依据** 能看看她为什么这样判断。两张都像正面时不会硬分正背，不确定的先留下待确认。

确认顺序后再拼接，成品到第一个文件夹的 **处理后**，原图保留。单独点重命名会修改原文件名，点之前再检查一眼。

# 帕秋莉的编码书签

“两本表里叫法不一样也没关系，我们先认款，再认颜色和尺码。”

## 先把两本表放好

聚水潭表准备 **款式编码、颜色、规格、商品编码**；抖店表准备 **商品id(必填)、商品规格、商家编码(必填)**。选好后往下一页。

## 再把同款牵起来

左边选款号，右边选对应 PID，看看两边颜色再确定。右侧的相似颜色只是观察线索，不会替你自动认款。同款可关联多个 PID，PID 也可共享。

## 最后连颜色，核尺码

把对应颜色连接后再导出，未配对的颜色跳过并保留原编码。共享 PID 的同一抖店颜色不能重复占用。

尺码的中英文括号备注不参与匹配：`M(建议100-110斤)` 可对应 `M`。`M、L、XL、2XL` 仍分开核对；去掉备注后出现多个不同编码，会提示歧义而不是随便填一个。原表的体重备注不改写。

浮动教程会随着这三页一起翻；想安静整理时，把她拖到边上趴好就行。
