# 拼接图

加载图片/文件夹 → 按需点击智能排序 → 确认正反面 → 拖动调整 → 拼接。

进入工具与加载图片时不调用 AI。勾选 AI 后点击 **智能排序**，AI 跨全部图片识别正反面，并把同款、主体颜色相近的正反面配成一组；不同文件夹也可配对。不确定的组合待确认，单张集中放在末尾。关闭 AI 则使用本地智能排序。切换正反面不自动重排。加载期间可继续添加文件夹，新增图片排在后面，当前任务完成后继续处理，不重复读取已加载图片；新增图也仅在下次点击智能排序时参与 AI 识别。

可开启 Gemini 正反面识别，重新识别时保留人工标记；**识别依据** 可查看每张图的判断和可信度。文件名明确标示正背面时优先使用文件名。没有 AI 时用本地颜色分组与结构分析；不能确认时保留待确认，不从数量硬分正背。拼接保存到第一个文件夹的“处理后”，原图保留；重命名会修改原文件名。

# 商品编码匹配

选择聚水潭及抖店表格 → 左侧选款号 → 右侧对照颜色选 PID → 下一步配色 → 导出。

左右两栏分别显示全部款号/PID 的颜色，可独立滚动与搜索。选择一个聚水潭款号后，右侧按同名/相近色排序；这些指标只辅助观察，不自动替用户绑定 PID。可为同一款选择多个 PID，也可共享 PID，仍由颜色和尺码确定 SKU。未配对颜色跳过，保留原商家编码。没有导入款号对照表入口。

尺码匹配忽略中英文圆括号内的备注，聚水潭和抖店两侧使用同一规则。例如 `M(建议100-110斤)` 与 `M`、`XL（加绒款）` 与 `XL` 可以对应；`M`、`L`、`XL`、`2XL` 仍严格区分。若去掉备注后同一款号、颜色、尺码对应多个不同商品编码，继续标记歧义，不自动任选编码。原表中的商品规格和体重备注不改写。
