# 送审拼接图


加载图片或多个文件夹，顺序会先保留。需要 AI 识别时点击 **智能排序**，加载本身不自动调用 AI。

看看每一对是否同款同色、正面在前、背面在后。徽标可以点击修正，图片可以拖动调整；**识别依据** 能查看识别依据。两张都像正面时不会强行判定正反面，不确定的先留下待确认。

确认顺序后再拼接，成品到第一个文件夹的 **处理后**，原图保留。单独点重命名会修改原文件名，点之前再检查一眼。

# 商品编码匹配


## 选择表格

聚水潭表准备 **款式编码、颜色、规格、商品编码**；抖店表准备 **商品id(必填)、商品规格、商家编码(必填)**。选好后继续下一步。

## 关联款号与 PID

左边选款号，右边选对应 PID，看看两边颜色再确定。右侧的相似颜色只是观察线索，不会自动关联款号。同款可关联多个 PID，PID 也可共享。

## 颜色与尺码匹配

把对应颜色连接后再导出，未配对的颜色跳过并保留原编码。共享 PID 的同一抖店颜色不能重复占用。

尺码的中英文括号备注不参与匹配：`M(建议100-110斤)` 可对应 `M`。`M、L、XL、2XL` 仍分开核对；去掉备注后出现多个不同编码，会提示歧义并保留原值。原表的体重备注不改写。
