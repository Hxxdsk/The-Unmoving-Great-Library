# 拼接图

加载图片/文件夹 → 自动识别 → 点击正反面徽标确认 → 拖动调整 → 拼接。

可开启 Gemini 正反面识别，重新识别时保留人工标记；**识别依据** 可查看每张图的判断和可信度。文件名明确标示正背面时优先使用文件名。没有 AI 时用本地颜色分组与结构分析；不能确认时保留待确认，不从数量硬分正背。拼接保存到第一个文件夹的“处理后”，原图保留；重命名会修改原文件名。

# 商品编码匹配

选择聚水潭及抖店表格 → 左侧选款号 → 右侧对照颜色选 PID → 下一步配色 → 导出。

左右两栏分别显示全部款号/PID 的颜色，可独立滚动与搜索。选择一个聚水潭款号后，右侧按同名/相近色排序；这些指标只辅助观察，不自动替用户绑定 PID。可为同一款选择多个 PID，也可共享 PID，仍由颜色和尺码确定 SKU。未配对颜色跳过，保留原商家编码。没有导入款号对照表入口。
