# 大图书馆 · 商品资料工具箱

商品图片处理、商品编码匹配、送审资料生成和抖店批量草稿工具。

[下载 Windows 更新包](https://github.com/Hxxdsk/The-Unmoving-Great-Library/raw/main/releases/大图书馆工具箱-Windows.zip)

## 启动

解压完整更新包，运行 `启动工具箱.exe`。首次启动会检查运行环境，请保留完整目录。

需要业务 AI 功能时，在首页的 **API / 模型 · 管理** 添加 API、检测并选择模型。手动配色、编码匹配等本地功能不需要 API。

开发环境安装 `requirements.txt` 后运行 `app.py`。原始脚本位于 `original_scripts`，组件和界面扩展位于 `suite`。

## 桌宠

桌宠仅用于动画和交互，不提供教学、对话或 API 功能，不读取任务进度和资料。

- 拖动移动；提起时悬空摆动，放下时播放落地过渡。
- 拖到窗口边缘后吸附为扒窗形象；点击或拖动可恢复。
- 点击互动，双击睡觉或唤醒，右键暂停或继续动画。
- 36 张动作差分，按顺序单帧绘制，配合亚像素缓动；活动动画目标 50 帧/秒，待机 20 帧/秒。仅缓存小尺寸图片，窗口隐藏或最小化时暂停。

## 使用说明

各组件独立运行。桌宠不影响任务执行，也不会选择文件、改编码或操作浏览器。抖店组件只保存草稿，不直接发布。

业务 AI 的识别结果仍需核对。API 由当前 Windows 用户加密保存；无法保护凭据的系统仅在会话内使用。各组件所需的图片或文字会按该功能说明发送到模型。
